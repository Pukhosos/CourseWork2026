# Course Work 2026

**Topic:**
    ```txt
    Phylogenomic Analysis of Flap Endonucleases of the Xni Family.
    ```

**Aim:**
    ```txt
    To investigate the evolutionary conservation of the Zn-binding site in
    Xni/FEN proteins among COG0258 homologs.
    ```

## Missing Data

Some data files are huge and they have been interntionally not included in this
repository. Here is how to restore the original `/data/large` files:

- `cog-24.cog.csv`:
    1. Download `cog-24.cog.csv` from [NCBI page](
        https://ftp.ncbi.nlm.nih.gov/pub/COG/COG2024/data/
    )
    2. Put `cog-24.cog.csv` in `/data/large`
- `COGorg24.faa`:
    1. Download `COGorg24.faa.gz` from [NCBI page](
        https://ftp.ncbi.nlm.nih.gov/pub/COG/COG2024/data/
    )
    2. Unzip the archive and put `COGorg24.faa` in `/data/large`
